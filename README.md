# AIに作らせたブラウザゲーム
- AIが作成したブラウザゲームのソースコードを集めたリポジトリです。

1. ライフゲーム 2025/06/26
2. 進化シミュレーション 2025/06/27
3. 15パズル 2025/06/28

現在の作品一覧は `web/index.html` が正本です。机上のからくり工房（全10面）とホームページから移植した3Dルービックキューブを含みます。

ローカル起動は `npm start`（`http://127.0.0.1:4173/`）、テストは `npm test`。公開用フォルダは `npm run build:pages` で生成します。公開の移行手順・未実施の操作は [MIGRATION.md](MIGRATION.md) を参照してください。

## 生物進化シミュレーション 2026

[3D水槽](web/evolution-aquarium.html) は、2025年版・Part2とは独立した観察型シミュレーションです。水温、餌の供給、捕食者数、突然変異率を変更し、個体・世代・系統・形質分布を比較できます。

実験手順とモデルの前提は [3D水槽の観察ガイド](docs/evolution-aquarium-2026.md) を参照してください。
