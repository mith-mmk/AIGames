操作・この版について

Z / 左Shift：左フリッパー
/ / 右Shift：右フリッパー
SPACE：長押しで強度をため、離して発射。発射ボタンも長押し、または上へ100px引いて強度を調整し、離して発射。弱い球は発射レーンに戻り同じ球を再発射できます。P / Escでキャンセル。
倍率：バンパー5回で×2、その後3種類の機構で得点すると×3。接触・通過点に適用し、達成ボーナスは固定。失球・TILT・やり直しで×1。同じ球の弱打再発射では維持。
N / 揺らす：中央向きのナッジ。短時間の連打は警告、さらに連打するとTILTでフリッパー・加点が止まり1.5秒後にその球を終了。
効果音：最初の操作後に鳴ります。「音 ON/OFF」で切り替え。画面を離れると停止します。
P / Esc：一時停止、R：やり直す、C：視点
視点スライダーで横に近い10°から真上90°まで動かせます。低い角度は筐体観察向けです。左右ボタンを押したまま球を受けると保持できます。短く離してから押し直すと打ち出し、離す時間で狙いを変えられます。根元寄りはバンパーの脇を通るレーン、タイミングを変えるとバンパー群や高架ランプを狙います。スマホは左右ボタンを同時に長押しできます。画面を離れると一時停止します。

Rapier物理で球・機構を検証する初期プレイ版。衝突は簡略形状です。細いレーンガイドと小型スリングを配置し、上昇動作中のフリッパーに実接触した球だけ打ち返しを補助します。上げ切った状態では自動打撃せず、接触と摩擦で球を保持します。中央セーブは1回分から開始し、トップレーンABC達成で1回分へ補充します。消費後は中央落球で失球します。右の発射レーンへ戻った球は失球にせず、同じ球を再発射できます。右入口から奥を回り左へ返す高架ランプを復帰しました。左返却部は二本の金属レールで球を支えるワイヤーレーンです。装飾機構はすべてが動作するものではありません。
