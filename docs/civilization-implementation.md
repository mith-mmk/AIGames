# Chronicle Kingdoms 実装・確認記録

2026-09-10。設計は `civilization-redesign.md`、状態と命令の契約は `civilization-contract.md`。

## 起動

リポジトリ直下で `npm run serve` をフォアグラウンド実行し、`http://127.0.0.1:4176/web/civilization.html` を開く。ポート指定は `npm run serve -- 4177`。停止は Ctrl+C。

JavaScriptモジュールを使うためHTTP経由で開く。配信サーバーは `.mjs` をJavaScriptのMIMEタイプで返す必要がある。同梱サーバーは対応済み。公開環境への配信は今回実施していない。

## 反映した内容

- 既存の `web/civilization.html` を新実装へ切替。旧実装はGit履歴に残り、旧localStorageセーブは変更しない。
- シード付き大陸・群島、3サイズ、独立した文明数・速度・ラウンド上限設定、菱形地図のパン・ズーム・ミニマップ。
- 都市の市民配置・専門家・税率・生産予約、36技術、22兵種、19施設、政治・外交・交易・陸海戦・輸送、4種類の勝利。
- AIは自文明の公開ビューと命令だけで行動。新IndexedDBに手動保存・3世代自動保存、JSON入出力、状態検証後の復元。
- 状態・内政・戦闘・視界・AI・描画・保存・画面を `web/js/civilization/` のモジュールに分離。

## 確認結果

- `npm test` 成功。既存ゲームのチェックに新ゲームの10テストファイルを接続した。
- 新テストはデータ参照、命令境界、収支予測、市民配分、余剰、輸送・戦闘、勝利、視界非漏洩、保存再現性、AI、描画座標、12種類の設定端点を確認。
- ESLintエラー0件。CSSのブラウザ互換性に関する警告3件（accent-color、:has、outline）。
- 実ブラウザで標準開始、都市建設、AIを含むターン進行、自動・手動保存と再読込を確認。専用の検証データでは市民配分、生産追加、下船、宇宙船発射、条約承認、交易路作成と保存復元を確認。
- 1366×768と1920×1080の表示を確認。60ラウンド・240文明手番のAIシミュレーションで状態整合性を確認。

標準設定の4〜8時間というプレイ時間、全設定での長期バランス、全ブラウザ互換性は未実測。テストによるルール確認と長時間の人間による通しプレイは区別する。
