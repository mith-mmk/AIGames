# 難易度の段階と調整方針

難しさを鏡の数だけで決めません。序盤1〜3面は反射の読み方、中盤4〜6面は向きの組合せと制約、終盤7〜10面は既習ルールの応用です。操作が失敗しても光路を表示し、Undo・リセット・面選択・段階ヒントで試行し直せます。

## 区別する指標

1. **最短操作数**：初期状態から成功までに必要な90度回転の最少数。鏡の総数や光路の長さとは別。
2. **曲がり数**：成功光路で起こる反射の数。すでに正しい鏡・固定鏡も数える。光路の長さだけを反射数にしない。
3. **選択肢**：回転可能な鏡の数、全向き配置 `2^n`、成功配置の数、最短配置の数、異なる成功光路の数を区別。
4. **先読み**：次の反射の確認、1〜2反射先の比較、固定鏡からの逆算、通過点と最終到達を含む光路全体の確認。人間がどう読むかの設計仮説であり、自動探索の計算時間とは別。
5. **紛らわしさ**：不要な鏡、短いが条件を満たさない道、複数の成功分岐、空マスでの交差。光源・ゴール・鏡・通過点を見た目で混同させる方法は使わない。
6. **仕組みの数**：回転鏡 → 石 → 固定鏡 → 通過点の4ルール。終盤に突然未説明のルールを増やさない。

自動評価はこれらの数値のベクトルとして出力し、単一の「難易度点」にはまとめません。無関係な鏡を追加すると配置数だけが倍増するので、探索状態数や鏡数をそのまま難易度と呼ぶのは不適切です。人間の難易度には視認性、発見の順序、記憶負荷、ヒントの理解も関わります。

**成功配置**は全鏡の向きが異なる配置を数えます。成功光路に触れない鏡の向きを変えても別配置になります。**成功光路**は方向付き光路の列を比較して重複を除きます。手順の順番（A→B / B→A）を成功配置の数として数えていません。7面では D→G と D→E→F がどちらも正解で、それぞれ最短4手です。

## どこで何を考えるか

| 面 | 教えること / 新しい仕組み | 先読みの設計 | 紛らわしさ・調整意図 |
| --- | --- | --- | --- |
| 1 ひとすじの光 | 回転鏡・90度反射 | 次の1反射だけ | 鏡1個・障害物なし。光源とゴールを見つければ始められる |
| 2 ふたつの曲がり角 | 入射方向による反射 | 前半と後半を順に追う | 鏡2個を両方変える。上から来る光の向きを読む |
| 3 石をよけて | 石による遮断 | 4反射のうち直す2個を識別 | 2面と同じ最短2手。鏡数だけでは手数を増やさない |
| 4 遠回りの庭 | 既習の組合せ | 庭の外側へ4反射で迂回 | ゴールは近いが石が直行を妨げる。Eは不要 |
| 5 動かない道しるべ | 固定鏡 | 固定Fの出射から前後を考える | 最短3手を維持。鏡の総数ではなく制約を追加 |
| 6 灯りをともして | 通過点 | ゴールと通過条件を両方確認 | Aからゴールへ1手で届く近道は通過点不足。3手の遠回りが必要 |
| 7 ふたつの灯り | 既習ルール、2通過点 | Dの先を2反射程度まで比較 | 2本の正解光路を許可。余分に見える鏡にも役割がある |
| 8 外周の回廊 | 遠回りの応用 | Cから外周へ進み、最後の通過点まで読む | Cからゴールへ下がる近道は条件不足。最短は7面と同じ4手 |
| 9 交差する道 | 交差の明示（追加物体なし） | 光路を方向別に追う | 空マスの交差を反射と混同しない。7反射・5手 |
| 10 光の庭の完成 | 既習4ルールの統合 | 固定FからE・Gと3通過点を結ぶ | H/I/Jの余分な鏡、迂回、固定鏡。6手に増やす |

「何反射先を読むか」は厳密な認知量ではありません。途中結果が常に見えるため、すべての面を小さく試行することもできます。先読みしないプレイヤーを罰する隠し状態や制限は設けません。

## 探索と変更時の検査

`npm run solve:mirror-light` は全10面、合計1,254配置を完全列挙します。可動鏡は最大9個で、上限はコード上12個。固定鏡を探索ビットに含めません。成功配置、最短手数、代表操作列、反射数、成功光路数、各失敗理由（庭外・石・通過点不足・ループ）を JSON に出力します。

各鏡は独立した二値切替で、回転1回のコストは1です。初期配置と成功配置のハミング距離はその配置へ到達する最少操作数になり、全成功配置の最小値が最短手数です。単体テストでは別途、1回転を辺とする状態グラフの BFS を行い、この最短手数と照合しています。全配置の光路停止、代表解を実際に入力した成功、Undo/Reset、全8種類の反射方向、閉じたループと交差も検査します。

## 人間のプレイによる調整

今回のブラウザ検証は PC とタッチ入力の実プレイ経路・画像を確認したものです。初見の人間による難易度校正はまだありません。自動テストがすべて通ることを「誰にとっても適切な難易度」と解釈しません。

次の試遊では1〜3面で説明なしに反射を理解できるか、6面で通過点不足のフィードバックを読めるか、7面で2光路のいずれかを発見できるか、8面の外周を読み切れるか、9面で交差を誤解するかを観察します。クリアまでの操作数・リセット回数・ヒント段階・どの鏡で立ち止まったかを本人の了解のある手動記録で比較します。現実装に行動追跡や外部送信はありません。

調整は初期向き、不要鏡の数と位置、石による遮断、通過点、光路の長さ、ヒント文の順で行い、毎回全解探索を再実行します。ランダムな配置や時間制限で難しくしません。初見で操作につまずく場合は盤面を難しくする前にタップ対象・説明・色分けを改善します。
