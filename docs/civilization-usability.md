# 都市管理・移動操作の修正

2026-09-10

## 操作

- 都市管理で名前を変更できる。市民配置は都市中心と周囲20マスを実際の相対位置に配置する。北が上、東が右。中央は自動収穫、配置中は濃緑、固定は金枠、利用不可は減光表示。人数が人口と一致したときに適用できる。
- 都市画像は専用の透過PNG。地図上、都市管理の概観、中央タイルに使用する。
- Mで移動指定に切り替え、地面のタイルをクリックすると経路を表示する。右クリックも経路確認のみ。Enterで確定しEscで取消。選択時の立体ユニットの当たり判定を、移動先の地面判定へ混ぜない。
- 現在地、目的地、今ターンの到達地点を表示する。現在ターンの経路は実線、将来の経路は破線。確定後は部隊にカメラが追従する。Lで選択部隊へ戻れる。
- 自動継続は初期状態でオフ。チェックした場合だけ次の手番に継続する。未探索地の移動費は推定で、実際の地形や敵により到達位置が変わることがある。オフならその場合も残りの命令を消す。Wで既存の継続命令を解除できる。
- ミニマップはVで表示しクリックで移動する。CSS寸法を固定し、DPR対応の描画サイズを再利用して拡大し続ける不具合を修正した。視界、都市、部隊、現在の画面範囲を表示する。
- Hでショートカット一覧。テンキーで画面方向の1マス移動、Nで次の対応、Shift+Enterでターン終了、Cで都市管理、Rで研究、Dで外交、Homeで首都、Ctrl+Sで保存、Ctrl+Oで読込。文字入力とIME変換中はゲーム命令を発行しない。
