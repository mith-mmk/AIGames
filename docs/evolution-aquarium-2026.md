# 生物進化シミュレーション 2026

## 開き方

`npm start` を実行して [3D水槽](http://127.0.0.1:4173/evolution-aquarium.html)
を開きます。AI Games の作品一覧からも選べます。Three.js は既存の同梱版を使うため、
水槽の表示に外部 CDN は不要です。WebGL 2 が使えない場合は 2D 断面表示で実験を続けられます。

## 最初の実験：水温だけを変える

1. 「穏やかな海」のまま「同じシードでやり直す」を押し、速度を 8 倍にします。
2. 形質の分布で「適温」を選び、実験時間が 3 分に達したら一時停止して分布を確認します。
3. 一時停止したまま、水温だけを 13 ℃ に変更します。
4. 「同じシードでやり直す」から再開し、同じ経過時間で適温の分布と個体数を見比べます。

棒は現在の集団に占める割合、輪郭は開始時の割合です。グラフの縦スケールは最も高い棒に
合わせて変わるため、比較するときは棒の位置と山の形、棒にカーソルを当てて出る匹数を見ます。
「寒冷化」プリセットは餌も変えるので、温度だけの差を調べる場合はスライダーを使います。
魚を選ぶと両親の ID、系統、世代、エネルギー、各形質を確認できます。

## 時間ごとの分布を読む

「形質分布の時間推移」では、横軸はシミュレーション時間（秒）、縦軸は選んだ形質の値です。
各列の色の明るさは、その時点の生存個体に占める割合を表します。個体数そのものではなく、
異なる個体数の時点を比較できます。例えば平均値が同じでも、上下に分かれた二つの明るい帯が
見えれば、値の異なる二つのまとまりがあります。灰色の列は個体がいない時点です。
グラフをタップするか「時点を選ぶ」のスライダーを動かすと、保存時点の匹数と割合を確認できます。
2 秒ごとに最新 150 点（約 5 分間）まで記録し、絶滅時はその時点を追加します。リセットすると履歴も新しくなります。

## このモデルが扱うこと・扱わないこと

- 親が近くにいて、成熟とエネルギーの条件を両方満たすと子が生まれます。
  形質ごとに両親の値を混ぜ、確率で変異させます。生まれた後に遺伝形質が環境に合わせて変わるわけではありません。
- 個体で適温、移動・採餌の性質、体の大きさ、模様などが異なります。
  浅瀬は平均して温かく餌が多め、深場は暗く冷たい設定です。
  速く泳げる魚も高いエネルギーを使い、魚の体色・模様は居場所によって捕食されやすさに影響します。
- 8 系統のラベルは交配時に片方の親から引き継ぎます。実際の血縁全体や種分化を表すものではありません。
- 45 秒前後で残餌が消えること、最大 200 匹などの画面上の制約を置き、
  時間、生理、遺伝、行動を大幅に短縮・簡略化しています。実際の魚種や気候の予測には使えません。

## 検証

- `npm run test:evolution-aquarium`: 再現性、遺伝・突然変異、餌と飢餓、温度選択、捕食と保護色、境界と上限。
- `npm run playtest:evolution-aquarium`: Playwright / Chromium で 3D、魚の選択、操作、グラフ、WebGL喪失時、モバイル幅を検証。
  既存の Chrome を使う場合は `AQUARIUM_CHROME`、スクリーンショットを保存する場合は `AQUARIUM_SHOTS` を指定できます。
- `npm run build:pages` 後に `npm run playtest:evolution-aquarium -- --built` を実行すると成果物の起動とカタログ導線も確認します。
