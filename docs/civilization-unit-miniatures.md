# ユニット・ミニチュア刷新

2026-09-10。対象はユニットの画像、選択欄、表示演出。ルール・AIの判断・乱数・保存形式は変更していない。

## 素材と表示

- `web/assets/civilization/units/` に全22兵種の専用PNG。OpenAIの組み込みImageGenで生成し、生成プロンプトは同ディレクトリの `prompts.json` に保存した。
- 全22枚のRGBAと実際の透明画素を確認。元画像の画素は加工せず、表示時に透明な余白を除く座標を `unit-art-bounds.mjs` に記録した。
- 人型は標準倍率で高さ約48px、騎馬・兵器・艦船は幅56〜64px。画像は縦横比を維持し、足元の影と文明色の台座を合成する。
- 選択中の部隊、未選択なら最初の軍事部隊を代表表示。同じタイルのクリックで巡回選択し、積載中の部隊は船と右欄で確認する。
- 右欄の肖像、全スタック、部隊一覧で同じ画像を使用。HP・移動力・状態名、行動済みの彩度低下、選択時の発光を追加した。
- 都市内の部隊は手前に配置し、都市名と生産表示を代表部隊の高さに合わせて上へ移す。

## 演出

`unit-animations.mjs` がプレイヤー向けビューから表示専用のクリップを作る。移動180ms、戦闘300ms、選択発光360ms。戦闘には踏み込みまたは射撃、被弾フラッシュ、損害数値、撃破フェードがある。

設定から演出を無効化できる。未設定なら `prefers-reduced-motion: reduce` を尊重する。演出中は命令の重複を抑止し、パン・ズームを維持する。新規開始・読込・画面離脱で予約フレームを破棄する。AI演出は人間が観測した範囲に絞り、連続するAI手番全体で最大1.2秒まで再生する。

開始前に全画像を読み込み、読込失敗は兵種名・ファイル名と再試行ボタンで示す。
