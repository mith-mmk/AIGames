# 魔導からくり工房

32×32の小さな森に工房を組む3Dブラウザゲーム。鉄の自動納品から、物流の分岐・収納、結晶加工、魔導剣の量産、ゴーレム製造と自律補給、錬金術と転送門、世界樹の育成へ進めます。鉄100本は途中の達成目標として保持し、研究に合わせて次の目的を表示します。

## 起動・検証

```sh
npm ci
npm start
# http://127.0.0.1:4173/fantasy-automation.html
npm test
npm run build:pages
npm run playtest:fantasy
npm run playtest:fantasy-technology
node scripts/fantasy-automation-browser.cjs --built
```

新作だけTypeScript/Viteでビルドし、既存作品は従来どおり静的HTML/JSで動きます。`npm start` とPages梱包の前に新作をビルドします。配布用 `web/js/fantasy-automation/runtime/app.js` もGit管理し、ソース変更時に再生成して一緒にコミットします。`npm test` は配布JSと再ビルド結果の一致も検査します。Three.js0.180.0は同梱版を使います。

## ビルドなしの静的配信

checkoutに含まれる `web/` をそのままHTTP配信できます。Node.jsがあれば依存インストールなしで `node scripts/serve.cjs`、Pythonがあれば `python3 -m http.server 4173 --bind 127.0.0.1 --directory web` で起動し、`http://127.0.0.1:4173/fantasy-automation.html` を開きます。

入口は `web/fantasy-automation.html`、配布JSは `web/js/fantasy-automation/runtime/app.js`、CSSは `web/css/fantasy-automation.css`。Three.jsは `web/js/vendor/three-0.180.0/three.module.min.js` と `three.core.min.js`。すべて相対パスなので `/AIGames/` 配下でも動きます。

HTMLを `file://` でダブルクリックする方式は対応しません。ES modules・importmapの読み込みはHTTP配信で確認しています。ゲームを遊ぶだけなら再ビルド不要、TypeScriptの編集後やPages生成時には `npm ci` とビルドが必要です。

PagesではActionsの `npm ci` → `npm test` → `npm run build:pages` が新作を再ビルドし、`.pages-dist/` だけを公開artifactへ渡します。今回この経路のローカル検証まで行い、実際の公開は行っていません。

## 画面内の初回案内

初期画面には「はじめての工房づくり」が表示されます。「この設備を選ぶ」→地図の光る区画を左クリック、を一段ずつ進めます。設備を自動配置するボタンではありません。向きは目印の矢印と同じにし、違っていれば「設備の詳細を開く」→「回転 R」またはRキーで直します。

魔力発生炉まで配線すると、案内が木材1個の手動補給へ進みます。「設備の詳細を開く」→木材のアイコンスロットを押すと1個補給できます。その後「1×で動かす」を押すと、魔力生成10秒・採掘・精錬・搬送の順で最初の自動納品が進みます。正常な待ち時間と、詰まり・断線などの確認事項を区別して表示します。

最初の納品後は木材採取場と燃料ベルトを案内します。全14段階を終えると「自由建設へ」。途中でも「案内を閉じる」で自由建設でき、上部メニュー「はじめての案内」で再表示できます。案内は現在の設備と進行から判定し、保存データを書き換えたり削除したりしません。

案内の目印が画面の外にある場合、「この設備を選ぶ」で見える位置へカメラを移します。視点を自由に動かす操作は維持しています。手順をまとめて確認したい場合は次の配置例を使えます。

## 最初のライン

最初は設備を持っているだけで、ラインはまだ組まれていません。設備キットは建設時に優先消費します。下の配置例は初期木材40・延べ棒20で建設できます。方向はすべて東（→）。建設中の区画座標は下部に表示されます。

1. 採掘機 `(12,16)`、ベルト `(13,16)`、製錬炉 `(14,16)`、ベルト `(15,16)`、納品箱 `(16,16)`。
2. 魔力発生炉 `(12,18)`、導線 `(12,17)` `(13,17)` `(14,17)` を置いて採掘機・製錬炉へ接続。
3. 木材採取場 `(9,18)`、ベルト `(10,18)` `(11,18)` を置き、燃料を魔力発生炉へ送る。
4. 少し待つと木材→魔力→採掘→精錬→納品が動きます。最初の起動を早めるなら魔力発生炉を選び木材を1個補給。

開始直後は魔力が0なので、採掘機と製錬炉は停止表示になります。配線と燃料供給が揃うと復旧します。出力は矢印側、入力は隣接区画から受け入れます。鉱脈と森林はMVP中に枯渇しません。

## 操作

| 入力 | 操作 |
| --- | --- |
| 左クリック / 1本指タップを離す | 建設・施設選択 |
| 2本指移動 / ピンチ | 地図移動 / 拡大縮小。建設はしません |
| ↶ 配置取消 / Ctrl・⌘ Z | 直近の未稼働の配置を全額取消。読込後の履歴なし |
| 左ドラッグ（ベルト選択中） | ベルトの連続配置 |
| R | 建設方向・選択設備を回転 |
| Shift＋クリック | 設備を複製して建設種類を選ぶ |
| X＋クリック | 確認して撤去 |
| Delete（設備選択中・地図にフォーカス） | 対象を確認して撤去。取消・Escで戻る |
| Esc | 建設・撤去モードを取り消す |
| Space | 一時停止・再開 |
| 1〜6（地図にフォーカス） | 登録した設備を選択 |
| 右ドラッグ / WASD | 視点移動 |
| 中ドラッグ / Q・E | 視点回転 |
| ホイール | ズーム |

視点キーは地図をクリックしてから操作します。上部メニューから視点リセット、保存、読込、操作説明を開けます。設備選択で停止原因、内部品、進捗、魔力、補給・回収を確認できます。UI操作は地図に建設しません。

## 保存とゲーム内時間

IndexedDBの1スロットに、地形・設備・方向・内部在庫・搬送品・進捗・魔力・納品数を保存します。「読込」で保存時の状態へ戻ります。保存形式version4を検証して保存します。旧version1／2／3は元の形式を検証し、設備・在庫・進捗・研究を保って移行します。転送門の設定・待機時間・搬送履歴、品ごとの通過履歴、世界樹の成長も保存します。明示的に保存するまでは元の保存枠を書き換えません。不明な版・破損データはエラーとして表示します。保存不可でも現在のプレイは継続できます。新しい工房を始めても、保存するまでは前の保存枠が残ります。

20Hz固定ステップ。0×は停止、1×/2×はゲーム内時間の倍率です。タブが非表示の間は停止し、オフライン進行は行いません。描画フレームから生産結果を計算しません。

## 補足仕様

- Input容量8、output容量4。搬送ベルトは1個。出力詰まりでは完成品を保持。
- 素材と魔力は開始時に確保。予約済み素材は作業中の専用領域に保持し回収できず、完了時に消費。配線切断中は処理を停止します。
- 魔力発生炉は蓄積30＋完成した魔力の未格納残分を内部に保持。空き容量へ少しずつ補充し、端数の残留で永久停止しません。
- ベルトの通常撤去は木材1・鉄の延べ棒1を全額回収。それ以外の建物は内部品と建設費の半分（端数切り捨て）を回収。すべての撤去操作で対象と回収予定を確認します。部分的に魔力へ変換済みの燃料は返さず、木材と魔力の二重回収を防ぎます。
- 回収した品は所持資材に入り、元の生産由来と手動で取り出した履歴を保持します。手動で取り出し・再投入した品は自動生産実績と自動納品に算入されません。採掘機から加工・搬送された延べ棒と魔導剣が自動納品対象です。木材の手動燃料補給は、この判定に影響しません。
- 建設可能性はゴースト色、方向は矢印、魔力接続は青/紫/橙の印で表示。出力先の接続も確認できます。
- 設備・費用は `definitions.json`、レシピは `recipes.json`、研究条件は `technologies.json`。モデルはオリジナルのプリミティブ。参考資料の他社画像は使用しません。

## 技術ツリーと収納箱

上部の「技術ツリー」から分岐、前提、現在の実績、解放される設備を確認し、条件を満たしたノードを研究します。魔導剣は直近60ゲーム秒の生産速度を測り、最高10本/分と自動納品10本で量産技術を達成します。累積納品数とは別の条件です。

収納箱は32個まで保管してベルトへ先入れ先出しで送り出します。納品箱は鉄の延べ棒と魔導剣を消費して実績へ加算します。増設用の延べ棒を手元に確保するには、納品前に収納箱で受けて回収してください。メニューの「木材を手採取」は木材切れからの復旧用です。

各パネルの「閉じる」で地図を広く表示でき、上部の対応ボタンから開き直せます。建設パレットを閉じると建設操作も解除します。詳しい条件、材料、保存移行、確認結果は [第2段階の技術ツリー](technology.md) に記載しています。

## 視覚UIと第三段階

収納箱を選ぶと手持ちと箱のアイコンスロットが左右に開きます。クリックで1個、Shift＋クリックまたは全量モードでまとめて移動します。空き32個の上限と由来を表示し、Tab・Enter・Spaceでも操作できます。建設一覧はカテゴリ別の複数列。☆でクイックスロットへ登録し、通常は6枠だけを表示します。詳細を閉じても機能と保存を保持します。

鉄の納品後は現在の実績と研究から次の目的を表示します。第三段階は刻印台と躯体工房で魔導核と躯体を作り、覚醒炉でゴーレムを製造します。補給所は収納箱の在庫を魔力発生炉や加工設備へ運び、燃料／素材を切り替えられます。

[視覚UIの操作と検証](visual-ui.md) / [第三段階の進行・保存](stage3.md)

## 第四段階と操作案内

建設一覧は「すべて」から設備名・素材・用途で検索できます。◆印は次の進行に関係する設備です。登録先1〜6を押し、設備の☆でショートカットへ登録します。未解放の設備にも費用と解放条件を表示します。

「♟？」またはメニューの「ゴーレムの使い方」から、現在の工房に合わせた8段階の案内を開けます。研究、部品製造、覚醒、補給所への配属、収納箱、燃料／材料の方針、供給、稼働実績を確認します。設備の再建は不要です。選択設備の撤去は詳細のボタンかDeleteで確認画面を開きます。対象と回収予定を確認でき、キャンセル・Escで取り消せます。確認中は一時停止し、閉じると元の速度に戻ります。

第四段階は錬金精髄→転送核→送信門と受信門→世界樹の種→世界樹の成長です。詳細は [第四段階の仕様と検証](stage4.md) を参照してください。

[タッチ操作・配置取消・旧セーブの復旧](touch-recovery.md) に操作と検証範囲を記載しています。製錬炉は鉱石を延べ棒へ加工し、魔力発生炉は木材を導線網の魔力へ変換します。詳細の入出力図、別々のアイコンと3D形状で区別できます。
