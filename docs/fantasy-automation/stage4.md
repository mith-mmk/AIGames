製造設備は素材を作業開始時に予約し、電力断で停止、出力満杯で完成品を保持する。3種類の材料を使う場合も、足りない材料すべての枠をまとめて確保し、先に届く2種類だけで入力庫が埋まるのを防ぐ。建設費は木材／鉄の延べ棒で、錬金工房8／10、転送核工房8／12、転送門8／8＋転送核1、育種工房10／10、世界樹12／6＋転送核1。

## 転送門を接続する

1. 同じ接続番号（1〜3）の転送門を2台建てる。
2. 設備詳細で1台を送信門、もう1台を受信門にする。
3. 送信門へ素材をベルトで入れ、導線で魔力を供給する。
4. 受信門の矢印側をベルトや設備へつなぐ。

同じ番号の門がちょうど2台で、送信1台・受信1台の時だけ動く。3台以上、片方だけ、同じ役割、送信側の魔力不足、受信側満杯は具体的な理由を表示して待つ。受信門に魔力は不要。送信門は入力8品・通常出力なし、受信門は入力なし・出力4品。1ゲーム秒に最大1品、送信側の魔力2を使って実物を移す。新着品が同じステップで次の設備へ飛び移らない。

中身がある門は役割・接続番号を変更できない。回収して空にしてから変更する。同じ設定を繰り返しても転送間隔は短縮しない。通過履歴を保持するため、同じ品を往復させても初回転送実績を増やせない。新しいレシピで生まれた完成品は別の品として扱う。

## 世界樹を育てる

育種工房で自動生産した種を、手で回収せずに送信門→受信門→世界樹へ送る。世界樹は魔力不要で、対象の種を最大1ゲーム秒に1個消費し、1本につき10まで成長する。手動由来・手動回収済み・転送前の種は消費せず、先頭に保持して理由を表示する。回収して経路を直せる。成長10以降の余剰種も保持し、回収できる。

世界樹を撤去しても消費済みの種は戻らない。残っている入力品と通常の建設費半分は回収できる。成長実績は達成履歴として残る。

## 保存と案内

保存v4で転送設定、待機時間、直近経路、品ごとの通過履歴、各世界樹の成長と累積実績を保存する。旧v1/v2/v3を元の形式で検証し、物品・進捗・魔力・ゴーレム・研究を保って移行する。新資源・転送／成長実績は0から始まり、旧品に転送履歴を付与しない。読込だけでは元の保存枠を書き換えない。

「ゴーレムの使い方」は研究から自動補給の確認まで8段階。現在の設備と在庫を読み、範囲外・木材なし・手動由来・方針違い・満杯・作業中を区別する。設備の作り直しを前提にしない。建設一覧の検索、進行に応じた◆印、6枠の登録先ボタンと併せて次の操作へ進める。

## 通常命令による到達確認

`npm run check:fantasy-stage4` は新規seed662から全12研究を進める。資材・地形・研究・実績を直接書き換えず、1,014件の命令が成功、失敗0。1,350ゲーム秒で世界樹を成長10まで育て、世界樹の覚醒を研究した。錬金精髄40・転送核8・世界樹の種10を自動生産し、初回転送20個、成長10を記録した。これは操作に使う実時間を含まない、検証用配置のゲーム内時間。

原料は森林・鉱脈から生産して収納し、材料方針のゴーレム3体が新工房へ補給する。作業員は実際に作ったゴーレムを回収・手動配置し、建設用の木材手採取と延べ棒の回収、補助魔力炉への手動燃料補給を使う。製造材料は手動投入しない。全魔力炉の燃料まで無人化した証明ではない。

状態ファイルと命令の記録は [phase4/fixtures](../../artifacts/fantasy-automation/phase4/fixtures/reachability.json)。スクリプトは通常stdoutだけに出力し、`--fixtures <dir>` を明示した時だけ保存データを生成する。
