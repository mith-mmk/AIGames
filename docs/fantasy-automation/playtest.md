# 検証記録

2026-10-13。Node 24.19.0、Chromium 151.0.7922.173（headless、SwiftShader）。Game Studio の Three WebGL Game / Web Game Foundations / Game Playtest の指針を使用。

## 論理・保存・ビルド

- `npm test`: 既存全ロジック・lintと新作を実行。既存ゲームのチェックを削除していない。
- 新作は28テスト（clock7、simulation17、storage4）。TypeScript検査と新作対象lintエラー0。
- 100個の物品を、詰まった3区画のベルトから納品まで輸送。全tickで投入数＝施設内＋ベルト上＋納品数、最終100個到着。
- 100個の鉱石が50本の延べ棒に変換される全tickで物質量保存。開始時の予約素材は回収不可。
- 二段階ベルト更新、安定ID競合規則、更新配列順序非依存、30/144FPS・1/2倍速の同一ゲーム内時間の状態一致。
- 導線切断で予約済み作業を停止し、再接続で再開。出力詰まり後の回収で輸送復旧。
- 魔力1残留時の木材手動補給で再起動。完成魔力の残量を保存し、撤去で燃焼済み木材を二重回収しない。
- 自給ラインの採掘・木材燃料・精錬・納品を連続実行し、100本でクリア。手動品・手動鉱石からの製品は目標非算入。
- 保存は版・型・設備容量・予約状態・資源・地形・重複配置などを検証。不明な版と破損は拒否。
- `npm run build:pages`: 新作Viteビルドと既存静的梱包を実行、HTML/CSS/相対module/資産参照を検査。TypeScriptソース・テスト・検証画像は公開梱包に含めない。

## 実ブラウザ

`scripts/fantasy-automation-browser.cjs` が一時HTTPサーバーを起動し、終了時に閉じる。sourceと`.pages-dist`の両方を検証。

- 建設パレットとcanvasの実入力で、初期資源だけから12施設の自給ラインを構築。2倍速で採掘→精錬→自動納品が発生するまで確認。
- 一時停止、速度切替、5回の保存・読込、リロード後の再開で状態一致。IndexedDBで搬送品・進捗・自動属性・内部完成魔力も保存復元。
- 施設選択・回転、Shift複製、X撤去、ベルトの連続ドラッグ、UIクリックの地図への漏れを確認。
- 右ドラッグ・ホイール・視点回転・リセット。1440×900、390×844、320×844で横方向のはみ出しなし。
- WebGL context loss/recoveryで状態保持。WebGL不可・保存拒否でも日本語の操作表示と失敗メッセージを保持。
- ページエラー0、意図しない404応答0。画像で施設・方向・配線・HUD・resizeを目視確認。
- 既存「光の庭」のPlaywright回帰確認も実行。30面のdesktop/touch・undo/reset・保存・WebGL復旧・一覧導線が成功。

## 修正した不具合

1. 魔力1残留で新しい30単位を格納できず永久停止 → 内部完成魔力を保持し空き容量へ部分充填。
2. 手動ベルト補給がinputに滞留 → ベルトのitemへ投入。
3. WebGL不可でconstructorが止まりUIも消える → UIを起動し描画失敗を日本語表示。
4. WebGL復旧メッセージが保存完了表示を覆う → 復旧状態の解除とメッセージ併記。
5. 新規開始で方向・撤去モードが持ち越される → 初期操作状態へ戻す。
6. 施設が森林装飾に隠れる → 占有区画の装飾だけ抑制、撤去時に復元。
7. 選択パネルがメニューの保存ボタンを覆う → メニューを上に表示。

## 証拠と限界

`artifacts/fantasy-automation/source/` と `built/` の `browser-results.json` とPNG。`starter-producing.png` は実操作で構築した稼働工房、`viewport-320.png` / `viewport-390.png` は狭い画面の確認。

100本クリアまでの全時間待機は独立シミュレーションで検証。ブラウザではライン構築から最初の自動納品、操作と保存を確認。15〜30分の実ユーザー所要時間、実GPUの性能、Safari/Firefox、スマートフォンでの連続プレイは未測定。狭いviewportの表示を確認した範囲であり、スマートフォン実機での操作保証ではない。CSSにbaseline警告（新作2件）が残るがlintエラーはない。

mainへのマージ、Pages設定変更・デプロイ、CI待機は行っていない。公開可否や本番GPU性能をローカル検証だけで保証しない。
