# タッチ操作・配置取消・旧セーブの復旧

基点は `816c0de9b58ac3337ea820fc05d8e66f3fe6f36f`。保存形式version4、設備の内部ID `smelter` / `generator`、IndexedDBの保存先は変更していません。旧version1/2/3の検証・移行も維持しています。

## 操作

- 1本指でタップし、指を離すと1回だけ配置・選択します。触れた瞬間には建設しません。
- 2本指で地図を移動し、指の間隔を変えて拡大・縮小します。2本目が触れた時点で配置候補を取り消し、最後の指を離すまで配置しません。
- 1本指ドラッグ、タッチの中断、捕捉の喪失、画面のリサイズ、フォーカス喪失では配置しません。ジェスチャー後700msは互換マウス入力を抑制します。
- マウス左ドラッグによるベルト連続敷設は従来どおりです。
- 下部の「↶ 配置取消」、または地図にフォーカスしてCtrl / ⌘ Zで、直近の取り消せる配置を戻します。

配置取消は支払った資材を全額返し、設備キットで置いた場合はキットを返します。投入・搬送・生産・実際の魔力供給などに使用した設備は対象外です。空に戻しても使用履歴は解除しません。未稼働の配置は最大64件をそのセッション内だけで保持し、読込・新規開始で消えます。世界全体の進行や実績は巻き戻しません。

## 鉄が0になった既存セーブからの回復

1. 既存の保存を「読込」で再開します。読込だけで資材を追加することはありません。
2. 不要なベルトを選び、詳細の「撤去」を押します。
3. 確認画面の回収予定を確認して「撤去する」を押します。ベルト1本につき木材1・鉄の延べ棒1が戻ります。内部の品も回収し、手動回収の由来を保持します。
4. 回収した資材で正しい位置・方向へ敷き直します。

ベルトは建設費を全額回収します。それ以外の通常撤去は従来どおり建設費の半分を切り捨てて回収します。詳細ボタン、Delete、X＋クリック、撤去モードはいずれも確認画面を経由します。取消・Escでは在庫と設備を保持し、確認中だけ停止して元の速度へ戻ります。

## 炉の区別

| 表示名 | 役割 | 見分け方 |

| 製錬炉（旧表示: 魔導炉） | 鉄鉱石2＋魔力5→鉄の延べ棒1。物品を矢印側のベルトへ出力 | 橙色の四角い窯・煙突・延べ棒の受け皿。四角い窯のアイコン |
| 魔力発生炉（旧表示: 魔力炉） | 木材1→魔力30。導線網へ供給、ベルトへの物品出力なし | 開いた柱の間に浮かぶ青い結晶・導線端子。菱形結晶のアイコン |

一覧、ショートカット、詳細、初回案内、技術ツリー、ゴーレム案内の表示を更新しています。旧名での一覧検索も可能です。履歴セーブの状態文は画面表示時に旧名を読み替え、読み込んだだけでは保存枠を書き換えません。

## 検証

```sh
npm test
npm run build:pages
node scripts/fantasy-automation-recovery.cjs
node scripts/fantasy-automation-recovery.cjs --built
node scripts/fantasy-automation-phase4.cjs --ui-only
node scripts/fantasy-automation-phase4.cjs --built --ui-only
node --import tsx scripts/fantasy-automation-stage4-reachability.ts --nofixtures
```

新規入力テストは、単指の離す時の確定、遅れて触れた2本目、両方の離す順序、3本指、中断、UI上の2本目、リサイズ、捕捉喪失、マウス互換入力、従来のマウス敷設を検査します。回収テストは資材・由来の一致、キット返還、二重取消防止、100回のベルト建設撤去、使用後の取消拒否、実際に魔力を通した導線の取消拒否、読込での履歴消去を検査します。

ブラウザ検証はChromiumでCDPから複数の実タッチイベントを送り、390px・320px幅で移動・ピンチ・中断・誤建設ゼロ・取消・旧セーブの回収と再建設を確認します。デスクトップでは炉の区別、X・撤去モードの確認、歴史的version3保存の在庫・ID保持を検査します。ソース配信とPages生成物で同じ検証を行い、結果とスクリーンショットを `artifacts/fantasy-automation/recovery/` に記録します。

物理iPhone/iPadおよび実機Safariでは未検証です。Chromiumのタッチイベント列と単体のPointerEventテストを、実機iOSでの動作保証とは扱いません。

今回の結果は `recovery/summary.json` に集約しています。既存ゲームを含む `npm test` が成功し、新作は137件のTypeScriptテスト＋固定クロック7件が成功しました。Pages梱包306ファイル、ソースと生成物のタッチ・旧保存回復、既存UIの研究・ゴーレム補給・320/390/1440pxリサイズ、初回案内だけでの390/320pxタッチ進行、単独配布先での建設も成功しています。通常コマンド1010回・1346ゲーム秒で世界樹の成長10に到達しました。CSSには既存の互換性警告2件があり、エラーはありません。

既存Siteの更新用配布物は同じURLへ適用するため、同一ブラウザ・同一オリジンのIndexedDBをそのまま使います。ストレージを消去せず再読込してください。別URLへコピーした場合にはブラウザの保存枠は共有されません。
