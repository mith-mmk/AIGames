# 収納・建設・物流の視覚UI

2026-10-15の使い勝手改善。Game StudioのGame UI Frontend／Game Playtestを適用し、木材と真鍮の枠、アイコンと数量、短い状態表示を基調にする。通常の地図中央を空け、詳細は必要な時に開く。

- 収納箱は所持品と箱を左右に並べ、資源アイコンのスロットを押して移す。1個／まとめて移動、空き容量、由来を表示する。native buttonでTab・Enter・Spaceとタッチ操作に対応する。数字入力は補助操作へ下げる。
- 設備一覧はカテゴリ別の2〜3列に整理する。よく使う設備は6つのショートカットへ登録し、ボタンまたは数字キー1〜6で選ぶ。未解放・費用・現在の選択を示す。ショートカット設定はゲーム保存枠と別に保持する。
- 目的は生産・納品・研究状態から決める。研究可能なノードを見つけやすくし、鉄100本達成後も古い目的を表示し続けない。初回案内は完成済み工房を見本の配置へ戻すよう求めない。
- ベルトは連続した山形の進行印と搬送品で方向を示す。接続・未接続・素材不適合・詰まりに、形の異なる印を使う。色だけに依存しない。
- 建物には出口の突起と矢印、受入可能な辺には入口の丸い印を設ける。入力は実際の規則どおり隣接辺から受け入れ、固定の一方向だけを入口として描かない。分岐器の2出口も示す。
- 配置プレビューと回転を同じ表現にそろえ、設備が置かれる前にも向きと接続先を確認できる。モーダル一覧を操作中は地図の建設・カメラ操作を遮断する。

既存の保存・読込、回収、手動補給、撤去、研究、初回案内と、各パネルの閉じる・再表示を維持する。旧保存形式の移行と第三段階は [stage3.md](stage3.md) を参照。

改修前の実ブラウザ画像と元runtimeのSHA-256は `artifacts/fantasy-automation/visual-ui/before/` に保持する。完成後の実クリック検証、狭い画面、物流の状態別画像を同じディレクトリ内に記録する。

## 実操作検証

[前後画像と結果一覧](../../artifacts/fantasy-automation/visual-ui/README.md) にソース版・配布版の収納・登録・方向・目的・ゴーレム補給・保存・画面幅の14項目を記録した。保存通知とモバイル案内の隠れを修正し、390/320幅の全14案内も実操作で完了。設備を選んだ直後のRは最新buildの専用検証で確認した。
