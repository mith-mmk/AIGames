# 共通機械と手動出荷（保存形式v5）

建設一覧は21種類から15種類へ整理しました。既存の加工機械に製品レシピを追加し、新しい機械種類は追加していません。

| 共通機械 | 統合した設備 | 製品レシピ | 新設時の建設費 |
| --- | --- | --- | --- |
| 製錬炉 | 魔晶精製炉 | 鉄の延べ棒・精製魔晶 | 木材4・延べ棒8 |
| 魔導組立機 | 刻印台・躯体工房・覚醒炉・転送核工房 | 魔導剣・魔導核・鉄の躯体・ゴーレム・転送核 | 木材8・延べ棒12 |
| 錬金工房 | 育種工房 | 錬金精髄・世界樹の種 | 木材10・延べ棒10 |

共通機械の新設費は各統合対象の資源別最大値です。旧設備は当時の建設費を個別に保持し、通常撤去の返却額を変えません。レシピ切替で費用を再計算したり、資材の差額を返したりしません。未稼働配置の全額取消とベルト撤去時の全額返却も維持しています。

9レシピの材料・加工時間・魔力消費・研究条件は変更していません。建設種類を選ぶと下部に製品選択が現れ、配置後も詳細の「生産レシピ」で変更できます。研究前の製品は選べません。稼働中・予約素材のある間は変更できず、互換性のない庫内品がある場合も拒否します。先に終了・排出を待つか、必要な品を回収してください。

採掘3種、魔力発生炉と導線、ベルト・分岐器・収納箱、ゴーレム補給所、転送門、世界樹は独立した役割として残しています。製錬炉と魔力発生炉の名前・形・機能の区別も維持しています。

## 出荷所の使い方

旧納品箱は「出荷所」です。木材・鉄の延べ棒・魔導剣の搬入品を32個まで保持します。**到着時に即消費・即加算する旧動作から、確認して手動出荷する動作へ変更しました。** 満杯なら上流で止まり、品は保持します。

1. 出荷所を選び、出荷元を「搬入庫」または「手持ち」にします。
2. 品物と個数を選び、依頼への割当数・売却数・売上を確認します。
3. 「確認して出荷」を押すと品を消費し、未達成の依頼へ優先割当した後、余剰を売却します。
4. 条件達成後に技術ツリーから研究します。研究そのものは自動完了せず、解放した設備・レシピ名を表示します。

鉄10本の自動生産品の出荷で結晶加工を研究可能にし、魔晶採掘機と精製魔晶レシピを解放できます。剣10本の出荷は、前提研究と最高10本/ゲーム内分の生産条件と合わせて量産技術の条件になります。鉄100本は累計出荷の記念実績として保持し、追加報酬は付けていません。

自動生産後に回収した対象品は、回収時に出荷対象の由来を保持し、手持ちから依頼へ使えます。初期資材・購入品・手動材料から製造した品は売却のみです。旧保存で既に手回収済みだった品には新しい由来を推測して付与せず、売却対象として保持します。材料として再投入した品は、従来どおり自動生産実績を増やしません。

## ゲーム内の会計と復旧

単価と依頼数は `web/js/fantasy-automation/market.json` に集約しています。外部課金・外部決済はありません。

| 品物 | 売却額/個 | 購入額/個 |
| --- | --- | --- |
| 木材 | 1コイン | 購入なし |
| 鉄の延べ棒 | 10コイン | 30コイン |
| 魔導剣 | 40コイン | 購入なし |

資金は工房共通です。出荷所の詳細から建設用の延べ棒を購入できます。資金0・鉄0でも、森林から木材を手採取し30個を売れば延べ棒1個を購入できます。出荷所自体も木材6だけで建設できます。購入品は依頼の実績を増やしません。

延べ棒を購入して即売却すると30→10、購入した鉄2本から剣を作っても鉄代60に対して売上40です。購入・売却は数量、在庫、所持金、整数上限を検証してから一括反映します。空在庫の再送や不足資金の購入は状態を変更しません。売却済みの品は回収できません。未出荷の搬入品は通常の回収・撤去で回収できます。

自動出荷・自動売却・自動購入は今回実装していません。物流による搬入と、プレイヤーが確認する出荷を分けています。配線ルールと魔力供給範囲も変更していません。

## 保存移行と検証

保存先のIndexedDB・スロット名は同じです。v1〜4は当時の設備・技術定義で検証後、v5へ移行します。配置済み設備のID・座標・方向・元レシピ・在庫・予約素材・進捗・研究・実績を保持します。旧キットは元の返却価値を持つ券として共通機械に利用でき、配置取消では元の券へ戻します。通貨は0から開始し、過去の納品を再換金しません。読込だけでは保存枠を書き換えず、明示的な保存で更新します。

```sh
npm test
npm run build:pages
npm run playtest:fantasy
node scripts/fantasy-automation-recipes-shipping.cjs --built
npm run playtest:fantasy-guide
node --import tsx scripts/fantasy-automation-stage4-reachability.ts --nofixtures
```

現行の受入ブラウザ検証は `fantasy-automation-recipes-shipping.cjs` と更新した初回案内シナリオです。以前の21種類・v4・即時納品を前提にした詳細ブラウザシナリオとその画像は、過去版の検証記録として残しています。

新しいブラウザ検証は、実際のマウス/タッチ操作、15種類の一覧、3共通機械の配置前後の製品選択、手動出荷と研究解放、売買、配置取消、真のv4保存の移行、再読込を確認します。実機iOS/Safariは未検証で、Chromiumのタッチエミュレーションです。通常進行の到達検証は実際のゲームコマンドで手動出荷を再現し、ゲーム本体に自動出荷処理を追加しません。
