# 翠嵐麻雀 v1.2.0

三麻・四麻の3D麻雀ゲームです。対局の準備、局結果、終局精算、成績管理、バックアップを追加しました。前版のCOMランダム初期設定と濃い牌面を維持し、操作画面は引き続き3D卓と同じ1枚のCanvas内に描画します。ブラウザの起動用HTMLと標準のファイル選択機能だけを使用します。

## 起動

展開したフォルダーで、Node.js 18以降を使用して次を実行します。外部パッケージのインストールは不要です。

```sh
node server.mjs
```

ブラウザで `http://localhost:8080` を開きます。Windowsでは `start-windows.cmd` も使えます。Pythonで起動する場合は次のとおりです。

```sh
python3 -m http.server 8080 --directory dist
```

`dist/index.html` の直接ダブルクリックではなく、ローカルHTTPサーバーまたはHTTPSサイトから起動してください。ファイルの検証にはWeb Crypto APIを使用するため、HTTPSまたはlocalhostの安全なコンテキストが必要です。

Three.jsは既存の0.186.1に固定し、CDNから読み込みます。接続できない場合に備え、同じライブラリを `dist/vendor/three/` に同梱しています。この更新でライブラリの最新版調査や交換はしていません。

## v1.2.0の操作

### 席決めと起家

初回・新規対局では配牌前に席順を表示します。「仮東を決める」「起家を決める」「配牌して開始」の順に進みます。サイコロの結果と最初の親を確認してから対局を開始します。あなたの表示位置は常に手前で、他の参加者の席順と起家を抽選します。設定で席順・起家を固定することもできます。

新規対局の起家を自分に固定していた処理を修正しました。輪荘時には次の席へ親が移動し、連荘時には親を維持します。COMの打ち筋は新規対局でのみ抽選し、局の移動や途中再開では変えません。

### 打牌と結果

手牌を選び、「打牌」で確定します。確定前は選び直せますが、確定した打牌は取り消せません。チー・ポン・カンなどは、可能な局面で操作列に表示されます。左右キー・Enter・Tabでも操作できます。

和了すると、和了牌を強調した手牌・副露、役、表ドラ・裏ドラ・赤ドラ・抜きドラの加算、符・翻、受取点、支払いが自動表示されます。複数ロンでは和了者を切り替えます。「点数内訳」から符の構成と適用ルールを確認できます。「確認して次局」を押すまで進行を止めます。

対局終了時は「確認して精算」で全参加者の精算表を表示します。素点、基準点との差、ウマ、オカ、最終得点を分けて表示します。終局後の新規対局操作でも、未確認なら先に精算画面を表示します。

### 点数推移と対戦成績

「メニュー」から「点数推移」「対戦成績」「データ管理」を開けます。グラフは対局開始時と各局の精算後の点数を記録し、供託は別表示します。点を選ぶとその局の数値を確認できます。長い対局は区間ごとに切り替えます。

完了した対局をこのブラウザのIndexedDBへ保存します。途中でやめた対局は通算成績に含みません。履歴には最終精算、局別結果、採用ルール、COM、点数推移、再生可能な操作記録を保持します。三麻と四麻の通算成績は別々です。

履歴から対局を削除すると再集計します。削除した対局は、同じ終局セーブを読み直しても自動で成績に戻りません。保存済みの牌譜は別に保持します。明示的なデータインポートでは削除した成績も復元できます。

### データの入出力

「データ管理」で全データをZIPに書き出せます。成績、設定、牌譜、現在の対局のJSON書き出しもあります。読み込み時は内容を検証し、統合・置換と復元対象を確認してから実行します。確認前には書き込みません。

同じ対局IDは重複集計せず、同じIDで結果が異なる場合は中断します。成績は読み込んだ集計値を信用せず、保存された対局結果から再集計します。変更は1回のデータベース取引で確定し、失敗時にはその取引を取り消します。取り込み前のデータを1世代保存し、「直前のインポートを取り消す」から戻せます。

設定だけの復元は、進行中の対局ルールを変更しません。自動保存スロットを復元する場合は、その保存対局へ切り替えます。旧v1.1.0の途中保存も読み込めますが、当時記録していなかった過去の局結果は補完しません。

## 収録ファイル

- `dist/`：そのまま静的配信できるゲーム本体とソース。
- `tests/`：採点・進行・保存・ZIP・UIの自動テスト。テスト用の牌姿は本番には含みません。
- `docs/CHANGELOG-v1.2.0.md`：変更一覧。
- `docs/DATA-v1.2.0.md`：保存形式、検証、復元、互換性。
- `docs/VERIFICATION.md`：今回の検証結果と未確認範囲。
- `docs/v1.2.0-evidence/`：ブラウザ画面、試験記録、連続対局結果。
- `docs/RULES.md`：標準役・31ローカル役・設定の説明。

## テスト

```sh
npm test
npm run test:stress
npm run test:fixtures
```

通常テストは外部依存なしで実行できます。ブラウザ試験だけはPython版PlaywrightとChromiumが必要です。Linuxでソフトウェア描画にXサーバーが必要な場合は次のように実行します。

```sh
SEIRAN_MODE=actions xvfb-run -a python3 tests/browser/v120.py
SEIRAN_MODE=screens SEIRAN_SIZES=844x390,568x320 xvfb-run -a python3 tests/browser/v120.py
```

画面検証はサイズを分けて実行できます。大きな画面でのソフトウェアWebGL描画には時間がかかります。

## 保存と公開に関する注意

成績は端末・ブラウザ・サイトの保存領域に属します。クラウド同期や端末間共有ではありません。ストレージを消すと消失するため、バックアップは別ファイルとして保管する機能です。容量不足や保存禁止時にはエラーを表示します。

このZIPはv1.2.0の完成ソースです。今回、既存Sitesへの再公開は実施していません。公開サイトのバージョン確認・公開後の動作検証も含みません。
