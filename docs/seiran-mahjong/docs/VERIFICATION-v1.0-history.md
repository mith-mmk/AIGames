## 同梱テストの実行

プロジェクトのルートで実行します。Node.js 18 以降を使用します。外部パッケージのインストールは不要です。

```sh
npm test
```

同等のコマンド:

```sh
node --test tests/*.test.mjs
```

作成時には Node.js 24 の次のコマンドで、各ケースの件数まで確認しました。

```sh
node --test --test-isolation=none tests/*.test.mjs
```

## 連続対局の検証

三麻20対局、四麻20対局を、12種類すべてのCOMを使って進行させました。内訳は東風24対局・東南8対局・一荘8対局です。合計319局、16,964操作が完了しました。

各操作で実牌の一意性、総牌数、手番と手牌枚数、点棒の保存を確認しました。50操作ごとと終局時に保存・復元しました。先付け・中付け、ツモ損なし、遅延カンドラ、頭ハネ、オープンリーチ、ローカル役の設定を切り替えた対局を含みます。再現用の seed と詳しい条件は [GAME-API.md](GAME-API.md) に記載しています。

この試験は限られた seed と設定の組み合わせに対する検証です。すべてのランダム配牌、全設定の直積、全端末に対する完全性を保証するものではありません。

## UI ロジックの検証

一時的な検証用環境で jsdom 26.1.0 を使用し、実際の HTML、app.js、設定画面、対局エンジンを読み込みました。Three.js の描画クラスだけをテスト用のアダプターに置き換えています。このため、この検証は WebGL の表示確認を含みません。

24 項目の検証には、初期起動、牌の選択、選択時の DOM 要素の維持、1回だけの打牌確定、ダブルクリックからの打牌、視点ボタン、8タブと全ルールの操作、31ローカル役の説明、COM選択、役別の設定保存、三麻への切り替え、37種の牌図鑑、手動保存、設定検索、操作ガイド、局結果、牌譜の前後移動、操作記録JSON、牌譜の書き出し・読み込み、非同期保存データとの競合防止、次局への進行を含みます。DOM イベントからの未捕捉エラーは0件でした。

## 3D の数値検証

Three.js のカメラと変換行列を使い、卓の外接直方体8頂点を射影しました。正規化デバイス座標の絶対値が1未満なら表示範囲内です。

| 描画領域 | 検証視点数 | 最大 X | 最大 Y |
| --- | ---: | ---: | ---: |
| PC 1440×636 | 3 | 0.6211 | 0.9260 |
| 横向きスマートフォン 844×228 | 3 | 0.3799 | 0.9260 |
| 縦向き 390×555 | 3 | 0.9374 | 0.6439 |

チー、ポン、大明槓、暗槓、加槓と手牌の配置を0〜4副露で検査し、25条件で境界ボックスの交差はありませんでした。最小の水平間隔は明槓4組・手牌2枚の条件で0.633 world、牌幅は0.46 worldでした。北抜き4枚も牌幅より広い間隔で配置しています。

これらは立体配置とカメラ範囲の計算であり、CSSの重なり、GPUの描画品質、端末性能を検証するものではありません。
