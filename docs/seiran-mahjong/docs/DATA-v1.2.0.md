# データ形式と安全性

## 版とファイル

ゲーム版は1.2.0、エンジンの保存版は2、データ一括形式は `format: seiran-data, schemaVersion: 2`。既存の個別保存の外側は `format: seiran-save, version: 1` を維持し、中の `state` にエンジンの版と状態を含む。旧エンジン版1は部分履歴として移行する。

一括ZIPには `manifest.json`、`settings.json`、`matches.json`、`statistics.json`、`saves/{auto,manual,previous}.json`、`replays/{matchId}.json` を収録する。存在するスロットだけを含む。各JSONには必要なデータの版を保持する。通算成績ファイルは参考値であり、取り込み時の正本にしない。

## 正本

終局したゲーム状態と、その局記録が正本である。対局ID、日時、参加者、確定したCOM、ルール、素点、局ごとの点数・供託・和了結果を保持する。最終精算・統計は再計算する。途中対局は成績として登録しない。

旧版からの移行は、残っている終了点と新たに記録した局のみを使用する。欠けた過去の手牌や局数を推測して埋めない。履歴画面に「部分履歴」と明示する。

## IndexedDB

データベース `seiran-library`、版2。ストアは `matches`、`saves`、`replays`、`meta`。一括取り込みはこれらを同じreadwrite取引に含める。変更に失敗すれば取引全体を取り消す。対応ブラウザではstrict durabilityを要求する。保存前にJSON・牌・点棒・版・ID・ZIPハッシュを検証する。

直前の取り込み前データを `meta/beforeImport` に1世代保存する。これは端末内の復元用であり、外部バックアップではない。容量不足で退避に失敗した場合は取り込みを実行しない。統合で既存の別内容とIDが衝突した場合も全変更を中止する。

削除済み対局IDは削除印で保持し、終局セーブの自動再保存からの復活を防ぐ。明示的なインポートはその対局の削除印を解除する。成績削除は牌譜の削除とは分離する。

設定・自動保存は旧localStorageにも互換用に複製する。インポートの正本はIndexedDBに置く。起動時には保存日時を比較し、新しい保存を採用する。

## ZIPとJSONの制限

入力64MiB、展開後合計128MiB、1エントリー32MiB、最大2,048エントリー、最大5,000対局。出力ZIPはSTORE方式。入力はSTORE/DEFLATEに対応し、DEFLATEはブラウザのDecompressionStreamを使う。暗号化ZIP、ZIP64、分割ZIPには対応しない。

重複パス、親フォルダーへの遡り、重複領域、サイズの不一致、CRC32不一致、manifestのSHA-256不一致、未知の版を拒否する。JSONは危険なプロパティ名を拒否する。CRCやハッシュは破損検出であり、電子署名・改ざん者認証ではない。全ての対局記録の正当性を外部大会基準で証明する仕組みでもない。

## 再現とプライバシー

当該ゲーム版、ルール、席、起家、山順序、操作列、操作直前の乱数状態を保持する。現版同士の再生では実際の処理を再実行して点数・局・状態を照合する。再生上限は12,000操作。旧版の不完全な記録や未知の将来版を無理に再生しない。

バックアップ・診断ファイルは暗号化しない。他家の手牌や山順序も含む。自動的な外部送信・アカウント同期は行わない。

実装根拠: IndexedDB 仕様のtransaction atomicity https://www.w3.org/TR/IndexedDB/ 、Web Compression Streams https://compression.spec.whatwg.org/ 。これらは実装方式の参照であり、この環境で実機の保存を確認済みという意味ではない。
