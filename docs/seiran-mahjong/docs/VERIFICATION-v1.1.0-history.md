## ブラウザ検証の実行条件

環境はNode.js 22.16、Linux版Chromium、Playwright、Xvfb、SwiftShaderです。描画はソフトウェアのWebGL 2であり、物理GPUの性能試験ではありません。

実行環境のChromiumは管理ポリシーによりURLへのナビゲーションを許可していないため、ローカルHTTP URLや公開Sitesをブラウザで開く方法は利用できませんでした。管理ポリシーは変更していません。代わりに、手元の配布ソースと同梱Three.jsをメモリー上のモジュールへ読み込み、外部ネットワークへ移動せず実際のアプリと描画をテストしています。

このオフライン検証はopaque origin上で動くため、localStorageにはメモリー上の代替実装を使いました。保存JSON・復元処理とCOMの維持は検証していますが、ブラウザを閉じた後のディスクへの永続保存、IndexedDBの持続性、ブラウザ標準のファイル選択・ダウンロード画面は最終確認していません。物理スマートフォン、iOS Safari、各社GPU、音声の出力品質も未検証です。

公開Sitesへの再デプロイは実施していません。ZIPの検証結果を公開先での動作確認として扱うことはできません。

## ブラウザ検証を再実行する場合

通常のゲーム起動に追加パッケージは不要です。以下は開発者向けの任意の検証環境です。

```sh
python -m pip install playwright pillow numpy
# 既存のChromiumを使用。見つからない場合はCHROMIUM_PATHを指定する。
python tests/browser/interaction.py
python tests/browser/embedded_touch.py
```

Xサーバーを必要とするLinux環境では、それぞれ `xvfb-run -a python ...` で実行します。検証用の画像とJSONは標準で `tests/output/` に生成されます。`SEIRAN_QA_OUT` で保存先を変更できます。テスト用のブラウザ起動引数は信頼できる同梱ソースの検証用であり、日常利用のブラウザへ適用するものではありません。
