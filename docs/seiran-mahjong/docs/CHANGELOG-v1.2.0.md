# v1.2.0 — 2026-10-17

## 対局エンジン

新規対局の起家固定を解除。席順抽選と二段階のサイコロによる起家抽選、配牌前のseating状態を追加。固定席順・固定起家も設定できる。画面上の手前はプレイヤーに固定し、参加者の識別子とCOMの個性を保持する。

局結果に手牌・副露・和了牌・採点・支払内訳を複製して保存する。局ごとの開始点・終了点・供託・親・本場を記録し、点数総額を検査する。最終順位は起家からの席順で同点優先を決める。牌譜には使用版、山順序、操作前の乱数状態を保存する。

## Canvas画面

席決め、和了結果、符・翻の内訳、終局精算、点数推移、過去の対局、通算成績、対局ルール、データ管理、インポート確認を追加。和了画面は自動表示し、確認までは停止する。小型横長画面の精算は1行の表、縦長画面は2行のカードで表示する。リサイズ直後は旧座標の操作領域を破棄する。

## データ保全

IndexedDBで成績・設定・保存・牌譜を管理。JSONと依存ライブラリ不要のZIPによるバックアップ。CRC32とSHA-256で破損検出、危険なパス・同名ファイル・サイズ超過・未知の版を拒否。インポート前の検証と確認、対象選択、統合/置換、ID重複抑制、同一ID異内容拒否、取引単位のロールバック、直前の復元取り消しを追加。

成績の二重記録、同時保存の競合、削除した現対局が再起動で復活する問題を防止した。集計値は元の履歴から再作成する。三麻と四麻を分け、ダブロンへの放銃を1局として数え、途中流局を局率の分母から除く。

## 互換性と検証

v1.1.0のセーブを移行できる。旧版で記録しなかった局は捏造せず部分履歴として表示し、その牌譜の完全再計算再生を禁止する。前版の12COM・ルール・牌造形・Canvas化を維持。検証の件数・範囲はVERIFICATION.mdを参照。
