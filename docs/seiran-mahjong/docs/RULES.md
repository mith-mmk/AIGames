# 翠嵐麻雀・採用ルールと点数計算

## 基本方針

標準役の構成と標準翻数は、日本プロ麻雀連盟の[採用役一覧](https://www.ma-jan.or.jp/activity/yaku.html)を基準にしている。三麻、赤牌、裏ドラ、複合役満、先付けなどの対局細則は本作の設定値に従う。対局開始時の全設定を保存し、途中再開でもその設定を維持する。

四麻はあなた1人とCOM3人、三麻はあなた1人とCOM2人。四麻136枚、三麻108枚。三麻では萬子の2〜8を常に除き、チーを禁止する。残る牌は各4枚で、赤五は通常の五と置き換える。赤牌を追加して総牌数を増やす処理は行わない。

牌のIDは物理牌単位、牌種は萬子0〜8・筒子9〜17・索子18〜26・東南西北27〜30・白發中31〜33。和了時も山・河・副露・手牌・抜き牌の物理牌を保持し、保存時に枚数と点棒総額を検査する。

## 対局の既定値

| 項目 | 既定値 |
| --- | --- |
| 人数・長さ | 四麻・東風戦 |
| 持ち点・返し点 | 四麻25,000 / 30,000点、三麻を新規指定した場合35,000 / 40,000点 |
| 赤牌 | 赤五萬・赤五筒・赤五索を各1枚。三麻の赤五萬は存在しない |

| カンドラ | 暗槓は即時。明槓・加槓は設定で即時または打牌後 |
| 役満 | 複合あり。特殊ダブルと3倍以上を許可 |

個々の役の通常翻数は門前時・副露時を別々に変更できる。0翻はその役を無効にする。もともと門前限定の役は、表示する門前条件を維持する。役満は別の倍率で変更する。ダブル役満全体を無効にすると最終倍率は1、3倍以上を無効にすると最終倍率は最大2になる。役満複合を無効にすると、成立した役満のうち最大の単独倍率を使う。

### ローカル役の重複

大七星は字一色を置き換える。一色三順は同じ3順子に由来する一盃口を置き換える。四連刻が有効に成立していれば三連刻を重ねない。一筒摸月と海底摸月、九筒撈魚と河底撈魚も重複させない。役満が成立すれば通常役とドラは点数に足さない。役満どうしの複合は設定に従う。

十三不塔は第一打までの純粋な初回ツモだけを対象とする。国士無双・天和・地和との二重加算はしない。通常の待ち牌検索やリーチ宣言の候補にも含めない。南北戦争は通常形にない専用の14枚を検査し、通常の局進行で手作りできるため待ち牌・向聴判定にも組み込む。

人和は役満、固定満貫、他役と足し合わせる5翻から選べる。固定満貫ではドラ等を加えず、通常の手の点数と比較して高い方を採用する。この方式選択が役別倍率より優先され、倍率は役満方式にのみ適用する。ただし0倍はどの方式でも人和を無効にする。八連荘は本場数ではなく親の連続和了数を数える。流局を挟むと連続和了数は0に戻る。

流し満貫は和了形評価から独立した通常流局時の処理。河に1・9・字牌だけを捨て、1枚も鳴かれていないことが必要。既定では副露不可、暗槓は門前を維持する。複数成立者はそれぞれ満貫ツモの支払いを計算して相殺する。供託の取得者は成立者の席順の先頭。和了扱いとして連荘・本場・終局を処理する。役別の翻数を変更した場合は門前・副露に応じた翻数と固定30符で精算し、0翻ならその状態の流し満貫を無効にする。役別の役満扱いを選んだ場合は指定倍率を適用する。いずれもドラは足さない。

## 先付け・中付けの採用定義

「後付あり」は最終の和了形に役があればよい。「中付あり」は和了直前の13枚相当の形について、物理的に可能なすべてのロン待ちに共通する手役が必要。「後付なし」はこの条件に加えて、最初の副露が実際にその役を構成しているか、その役が最初の副露時点ですでに手の内に完成していることを確認する。

最初の副露直後・強制打牌前に、手牌と副露の写しを記録する。白暗刻を持ったまま別の順子をチーするケースは先付けを認める。一方、123索を先に鳴いてから別の456萬・筒・索の三色同順だけを後で完成した場合、最初の123索はその役の構成に参加していないため先付けでは認めない。待ちの片方しか役がない形は中付・先付の両方で認めない。

先付けには多数の流派があるため、本作では[麻雀祭都・役の確定](https://mjradio.web.fc2.com/majansite-mirror/kansaki04.html)に掲載される論点のうち「共通の役の確定」と「最初の鳴きとの関係」を明示的に実装している。全役の完全確定を要求する流派にはしない。一発・海底・嶺上などの偶発役やドラは、事前に確定した手役に含めない。

## リーチ後の暗槓

既定は待ち牌と面子構成がともに変わらない場合のみ許可。4枚目を今回ツモしていること、槓前後の待ち集合が一致すること、槓前の各和了分解で対象の3枚が必ず独立した暗刻であることを検査する。たとえば111222333萬・456筒・7索の7索単騎から1萬を暗槓すると、123萬を3組と見る別解が消えるため既定では不可。設定で「待ち牌だけ不変」に変更すると許可する。考え方の根拠は[Mリーグ公式ルール第7条](https://m-league.jp/about/)の面子構成不変条件。

## 符と点数

通常手は副底20符。門前ロン10符、ツモ2符、役牌雀頭2符（連風雀頭は2/4符の設定）、単騎・嵌張・辺張待ち2符を加える。刻子は中張牌の明刻2・暗刻4符、么九牌は2倍、槓子は刻子の4倍。ロンで完成した刻子だけは明刻として扱い、門前そのものは維持する。合計を10符単位へ切り上げる。

平和ツモは20符。副露平和形のロンは最低30符。七対子は既定25符固定であり、一盃口・二盃口の分解と同時には加算しない。七対子の4枚使いを許可すると同種4枚を2対子に数えるが、物理的に5枚目を要求する待ちを作らない。

基本点は符×2^(翻+2)。子ロン4倍、親ロン6倍、子ツモは親2倍・子1倍、親ツモは全員2倍の基本点を払い、各支払いを100点単位へ切り上げる。5翻/上限到達は満貫2,000基本点、6〜7翻は跳満3,000、8〜10翻は倍満4,000、11〜12翻は三倍満6,000、13翻以上は設定により数え役満8,000または三倍満にする。

三麻のツモ損なしは、通常の4人打ちで不存在の子が払う額を残る2人へ半分ずつ配分して、100点単位へ切り上げる。満貫の子なら親5,000・子3,000、親なら子2人が6,000ずつ。通常支払額に丸めた後の不足分を分配するため、端数条件では四麻の合計に対し100点の差が生じることがある。

本場・供託は手牌の価値計算の外で精算する。通常のロンは1本場300点、ツモは相手1人につき100点。供託は1,000点単位で持ち越し、和了時に取得。複数ロンの供託は放銃者に最も近い下家の和了者が取得する。

責任払いは大三元の3種類目、大四喜の4種類目を確定させる牌を鳴かせた人に記録する。複合役満では対象の役満分だけを分離。ツモはその分を責任者が全額、他家のロンでは責任者と放銃者が折半する。本作の三麻の責任払いは役満のロン相当額を基準にする。

流局の不聴罰符は設定された総額を聴牌側・不聴側それぞれに100点単位で分け、割り切れない余りは起家からの席順に割り当てる。全員聴牌・全員不聴では移動しない。

## ドラと槓のタイミング

通常の表示は数牌9→1、風牌北→東、三元牌中→白。三麻の萬子は1→9、9→1。設定で表示牌そのものをドラとすることもできる。赤五は表示ドラと重複して数えられる。

裏ドラはリーチ/オープンリーチ成立者のみ。表ドラ・裏ドラ・赤ドラ・抜きドラは独立して切替可能。槓裏だけを無効にした場合は最初の裏表示牌のみを数える。北抜き牌は北抜き自体の1翻のほか、北が表示ドラ/裏ドラの場合その分も数える。

暗槓は即時にカンドラを表示。明槓・加槓を遅延設定にした場合は嶺上牌の打牌時に表示する。連続槓では前の未表示分を確定してから次の槓分を予約する。嶺上和了でその槓のドラを数えるか、搶槓で不成立になった槓の予定ドラを数えるかは独立設定。北抜きの補充は通常の山から行い、嶺上開花にはしない。

## 判定実装と検証

和了評価は4面子1雀頭のすべての分解と和了牌の使われ方を列挙する。複数の分解で点数が異なる場合は実支払合計が最大のものを選ぶ。三暗刻・四暗刻、平和、待ち符が分解に依存することを考慮している。向聴数は色ごとの面子・搭子・対子の可能な分解を組み合わせ、通常手・七対子・国士無双・採用時の南北戦争を比較する。牌種分布のキャッシュを使い、COMの多数の打牌候補を評価する。

実行例:

```sh
node --test --test-isolation=none tests/scoring.test.mjs
node --test --test-isolation=none tests/*.test.mjs
```

点数テストには全標準役、全ローカル役の成立と無効化、牌の枚数とID、赤2-1-1、七対子の4枚使い、待ち符、満貫境界、複合役満、表示ドラの巡回、カンドラタイミング、二翻縛り、先付けの履歴、三麻精算、リーチ後の面子変化を含む。さらに固定標準形から1枚ずつ抜いた待ち検証と、固定シードで生成した120種の合法な和了形を照合する。流し満貫・供託・責任払い・途中流局・対局保存・終局は進行エンジンのテストで確認する。
