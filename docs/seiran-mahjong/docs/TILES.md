# 麻雀牌と自動卓の造形

## 参照と実装方針

牌種・図柄の確認には、日本プロ麻雀連盟の「採用役一覧」に掲載された牌図を使用した。

- 採用役一覧: https://www.ma-jan.or.jp/activity/yaku.html
- 一索の参照図: https://www.ma-jan.or.jp/images/pai/01s/bam1.gif
- 八索の参照図: https://www.ma-jan.or.jp/images/pai/01s/bam8.gif
- 一筒の参照図: https://www.ma-jan.or.jp/images/pai/01s/bal1.gif
- 五筒の参照図: https://www.ma-jan.or.jp/images/pai/01s/bal5.gif

参照画像そのものは配布物に含めていない。牌面は `dist/js/render/tile-art.js` の独自SVG描画であり、生成画像やUnicodeの麻雀牌絵文字を使っていない。

## 全34種と赤牌

| 区分 | 実装 |
|---|---|
| 萬子 | 一〜九の漢数字を上段、赤色の「萬」を下段に配置。赤五萬は上下とも赤。 |
| 筒子 | 輪・中心穴・放射状の彫りを持つ同心円。数字ごとの配置と緑・濃藍・赤の配色を再現。 |
| 索子 | 節・切り口・中央の彫りを持つ竹。一索は扇状の羽を持つ鳥。八索は外側4本と内側の斜め4本を組み合わせる。 |
| 風牌 | 東・南・西・北の漢字。環境に依存しないベクター輪郭。 |
| 三元牌 | 白は完全な無地。發は緑、中は赤。 |
| 赤牌 | 赤五萬・赤五筒・赤五索。枚数はルール設定で変更する。 |

筒子の配色は、1筒＝濃藍の外輪と赤の中心、2筒＝緑・濃藍、3筒＝緑・赤・濃藍の斜め配置、4筒＝緑・濃藍の対角配置、5筒＝中央赤、6・7筒＝上部濃藍と下部赤、8筒＝左緑・右濃藍、9筒＝緑・赤・濃藍の3段である。索子は5索の中央、7索の上部、9索の中央列を赤にした。

図柄や書体は製造元によって異なる。このゲームは一般的な日本式の配置を採用しており、特定メーカーの牌の複製ではない。

## 書体のライセンス

牌と卓の銘板に使う漢字18文字の輪郭は Noto Serif CJK JP Bold のグリフをSVGパスへ変換した。配布時の実行にフォントの取得は不要。中央の風牌表示にも同じ輪郭を使用する。

- フォント: https://github.com/notofonts/noto-cjk/tree/main/Serif
- 元フォント: https://raw.githubusercontent.com/notofonts/noto-cjk/main/Serif/OTF/Japanese/NotoSerifCJKjp-Bold.otf
- ライセンス: SIL Open Font License 1.1
- ライセンス全文: `dist/js/render/Noto-OFL.txt`
- 変換した輪郭: `dist/js/render/glyphs.js`

## 3Dの構成

`TableView` は Three.js 0.186.1 を使用する。自動卓は厚みのある本体、金属の縁、織り目を描いた緑色のラシャ、4本の昇降スリット、中央のサイコロ受け、4面の点数表示、点棒用トレイを別々の立体として構成した。

牌は角を丸めた象牙色の本体、翡翠色の背面層、牌面を持つ。牌山は上下2段で表示する。四麻は136枚、三麻は108枚を基準にし、配牌・摸牌後の残り山と14枚の王牌を表示する。ドラ表示牌は王牌の対応する上段へ表示する。山の取り出し位置はサイコロの目と親の位置に応じて変わる。

## 表示と演出

- 牌山のせり上がりと配牌の移動。
- 上面の目が実際の出目に一致する2個のサイコロ。
- 摸牌・打牌・鳴きの牌の移動。
- リーチ宣言牌を横向きにし、立直棒を卓へ移動。
- 明槓・暗槓・加槓の形。暗槓の外側は伏せ、加槓は追加牌を重ねる。
- 3人打ちの北抜き牌。
- 和了・聴牌公開による倒牌、オープンリーチの手牌公開。
- 点数移動に対応した点棒のアニメーション。
- 手牌の選択・視点切り替え・ドラッグによる回転。

他家の非公開手牌は無地の表面として作り、視点を回しても本来の牌面を表示しない。全牌面のテクスチャは起動時にキャッシュし、対局ごとに増え続けない。牌山は同一形状をまとめて描画して負荷を抑えている。OSの「視差効果を減らす」設定では初期更新の演出を省略できる。
