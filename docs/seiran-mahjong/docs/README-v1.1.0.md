# 翠嵐麻雀 v1.1.0

三人打ち・四人打ちを切り替えて遊べる、ブラウザ用の3D麻雀ゲームです。自動卓、上下2段の牌山、中央のサイコロ装置、点数表示、河、副露、点棒置き場を Three.js で描画します。四麻はあなた1人とCOM3人、三麻はあなた1人とCOM2人で対局します。

**v1.1.0では、全COMの初期値をランダムにし、手牌・設定・保存・牌譜・結果を含む操作UIを単一の描画フレームへ移しました。HTMLのボタンやフォームは使用しません。前版の濃い牌面を維持しています。**

このZIPには、ゲーム本体、ソースコード、ローカル起動用サーバー、自動テスト、採用ルールと素材の説明を収録しています。

## ダウンロード版の起動

ZIPをフォルダーへ展開してから起動してください。`dist/index.html` を直接ダブルクリックする形式ではなく、以下のいずれかでHTTPサーバーを起動して開きます。実行には、WebGL 2とJavaScriptのES Modulesに対応するブラウザが必要です。PCとスマートフォンに対応する画面構成で、スマートフォンでは横向きを推奨します。

### Node.js 18以降

展開したフォルダーでターミナルを開き、次を実行します。

```sh
node server.mjs
```

ブラウザで **http://localhost:8080** を開いてください。サーバーを実行しているターミナルは開いたままにします。終了は `Ctrl+C` です。`npm install` は不要です。

`npm start` でも同じサーバーを起動できます。別のポートを使う場合は環境変数 `SEIRAN_PORT` を指定します。

### Python 3

展開したフォルダーで次を実行し、**http://localhost:8080** を開きます。

```sh
python3 -m http.server 8080 --directory dist
```

WindowsでPythonランチャーを使う場合は、`python3` を `py` に置き換えられます。

### Windowsの簡単起動

[start-windows.cmd](start-windows.cmd) をダブルクリックすると、インストール済みのNode.js、またはPythonランチャーを使って起動し、ブラウザを開きます。最初にブラウザが接続エラーを表示した場合は、サーバーの起動後に再読み込みしてください。

### Three.jsとオフライン利用

通常は **Three.js 0.186.1** を jsDelivr CDNから読み込みます。2026年10月17日にnpm公式レジストリで最新版を確認し、再現性のためその版に固定しています。[確認記録](docs/three-version.json)を同梱しています。

CDNへの接続を確認できない場合は、`dist/vendor/three/` に同梱した同一バージョンへ切り替えます。牌の図柄と必要なThree.js追加モジュールを同梱しているため、ZIP版はローカルサーバーからオフラインで読み込めます。UIの文字には端末のシステムフォントを使用します。接続できない環境では、初回の切り替えまで数秒かかる場合があります。

## 対局を始める

1. 上部の「新局」から、四麻・三麻と対局の長さを選びます。
2. 「設定」で細則やCOMの打ち筋を確認します。四麻・三麻の標準プリセットも用意しています。
3. 「対局を開始」で新規対局を始めます。配牌後、自分の手番になると手牌と操作ボタンが有効になります。

**対局ルールとCOMの割り当ての変更は、次の新規対局から適用されます。** 進行中の対局は開始時の設定を保持します。速度、視点、音、手牌分析、牌名表示は表示設定として変更できます。

## 操作

### 手牌・鳴き・和了

画面下の手牌、または卓上の自分の牌をクリック／タップすると牌を選択できます。画面下の「打牌」で確定します。画面下の牌はダブルクリックでも確定できます。確定前は選び直せますが、確定した打牌は取り消せません。

チー、ポン、カン、ロン、ツモ、北抜きなど、その局面で可能な操作が手牌下の操作列に表示されます。幅が足りない場合は「操作を選択」にまとめます。鳴きに複数の組み合わせがある場合は、使用する牌を選びます。リーチとオープンリーチは、宣言を選んでから打牌する牌を選び、確定します。

| キー | 操作 |
|---|---|
| `←` / `→` | 操作可能な手牌を選択 |
| `Enter` | 選択した牌を打牌／立直宣言牌として確定 |
| `Esc` | 選択・立直の選択を解除。開いている画面を閉じる／牌譜再生を終了 |
| `R` | 可能な場合にリーチの選択へ進む |
| `Space` | 可能な場合にロンまたはツモ |
| `N` | 三麻で可能な場合に北抜き |

「メニュー」→「対局の操作設定」の「鳴きなし」「自動和了」「ツモ切り」で自動操作を切り替えられます。速度は0.5倍・1倍・2倍・4倍から選べます。

### 視点・音・手牌分析

卓の右上から、俯瞰・真上・手元の視点へ切り替えます。卓をドラッグすると回転し、ホイールまたはピンチで拡大縮小できます。他家の伏せた手牌は、視点を変えても牌面を表示しません。

音と音量は「メニュー」→「対局の操作設定」、または「設定」→「表示・操作」で変更します。「手牌分析」では向聴数、受け入れ枚数、待ち牌、選択した打牌の危険度推定を確認できます。分析とCOMは、自分の手牌と公開情報を使います。危険度は推定であり、和了には役やフリテンの条件も必要です。

### 保存・再開・牌譜

- **自動保存**：打牌や鳴きの確定ごとに現在の対局を保存します。同じブラウザの同じURLで再度開くと続きから再開します。
- **手動保存**：保存画面で、任意の局面を手動保存できます。自動保存・手動保存・前回の対局の各スロットから再開できます。
- **ファイル保存**：保存画面でJSONを書き出し、別の端末のゲームで「読み込み」から再開できます。山、点数、ルール、乱数状態も含みます。
- **牌譜**：牌譜画面から卓上再生、前後の局面への移動、連続再生ができます。「対局に戻る」で進行中の対局へ戻ります。
- **牌譜の入出力**：「牌譜を書き出す」は、再生用局面と再開用データを含むJSONを保存します。「操作記録JSON」はエンジンの操作・イベント記録です。再読み込みには保存ファイルまたは牌譜ファイルを使ってください。

ブラウザの保存は端末・ブラウザ・接続先URLごとに分かれます。ブラウザのサイトデータを削除すると保存も消えるため、残したい対局はファイルに書き出してください。卓上再生用の局面は直近5,000件を保持し、画面のイベント一覧はページに分けて表示します。

## 採用ルールと設定

基本役は[日本プロ麻雀連盟の採用役一覧](https://www.ma-jan.or.jp/activity/yaku.html)を基準にしています。進行・点数・ローカル役の具体的な成立条件は、[採用ルールの詳細](docs/RULES.md)とゲーム内の「役・牌の図鑑」に記載しています。

| 分野 | 主な設定・対応内容 |
|---|---|
| 基本進行 | 三麻・四麻、東風戦・東南戦・一荘戦、配牌、摸打、和了、流局、連荘、終局 |
| 鳴き | チー・ポン・明槓・暗槓・加槓、鳴きの優先順位、同時ロン、三家和による流局 |
| リーチ | 一発、ダブルリーチ、オープンリーチ、フリテン、リーチ後の暗槓条件 |
| 三麻 | 萬子2〜8を除外、チー禁止、北抜き、抜きドラ、北抜き時の一発・嶺上の扱い、ツモ損 |
| ドラ | 赤牌の枚数、表ドラ・裏ドラ・カンドラ・カン裏、槓ドラの公開時期、槍槓・嶺上開花時の扱い |
| 役 | クイタン、後付け・中付け、役ごとの門前／副露の翻数、緑一色の發条件、七対子の4枚使い |
| 役満 | 複合役満、ダブル・トリプル以上の役満、純正九蓮宝燈・四暗刻単騎などの倍率 |
| 流局・連荘 | 九種九牌、四風連打、四槓散了、四家立直、聴牌条件、連荘時の二翻縛り |
| 点数・精算 | 符・翻、満貫〜役満、本場、供託、積み棒、責任払い、不聴罰符、ウマ・オカ、飛び |

**31種類のローカル役を個別に設定できます。** オープンリーチ、大車輪、四連刻、紅孔雀、百万石、人和、十三不塔、東北新幹線、八連荘、三色通貫、一色三順・一色四順、流し満貫、金門橋、南北戦争、燕返し、槓振り、十二落抬、五門斉、一筒摸月、九筒撈魚、大七星、花鳥風月などを含みます。標準プリセットではローカル役は無効です。

ローカル役には地域差があります。このゲームでは、[docs/RULES.md](docs/RULES.md)と図鑑に明記した定義を採用します。設定で採用有無、翻数・役満倍率、および用意された細則を変更できます。

## 12種類のCOM

**初期値は全席「ランダム」です。** 新規対局の開始時に各COMを12種類から独立に抽選し、その対局では固定します。同じ打ち筋が複数席に現れる場合があります。連荘・次局・途中保存からの再開では抽選し直しません。

対戦相手ごとに固定の打ち筋も選べます。既存の保存設定で固定選択してある席は保持します。「全員をランダムにする」で一括変更できます。各タイプは、速度・打点・守備・鳴き・リーチ・染め手・対子手・ドラ・役満・読みの10項目の数値で個性を持ち、設定画面からプロフィールを確認できます。

| 名前 | 打ち筋 |
|---|---|
| 疾風 | 速度重視 |
| 黄金 | 打点重視 |
| 一閃 | 門前リーチ重視 |
| 鳴神 | 鳴き速攻 |
| 玄武 | 鉄壁守備 |
| 静水 | ベタオリ重視 |
| 中庸 | 押し引き均衡 |
| 一染 | 染め手志向 |
| 双璧 | 対々和・七対子志向 |
| 赤銅 | ドラ重視 |
| 天極 | 役満志向 |
| 慧眼 | 捨て牌を読む分析型 |

COMは向聴数、受け入れ枚数、推定危険度、打点の見込みを評価して打牌や鳴きを選択します。相手の伏せた手牌や未来の山は判断に使用しません。

## 牌と3D演出

全34種と赤五萬・赤五筒・赤五索は、コードで構成したSVGとNotoの字形輪郭から描画しています。白は無地、發は緑、中は赤です。筒子の配置・配色、索子の節、一索の鳥、八索の斜めの竹を個別に構成しています。画像生成による牌面は使っていません。

3Dでは丸みのある牌の本体、厚み、側面、緑の裏面を持ちます。牌山のせり上がり、サイコロ、配牌・摸牌・打牌、鳴き、リーチ棒、倒牌、点棒移動の演出があります。造形の参照と実装は[牌と卓の説明](docs/TILES.md)にまとめています。

## 自動テストと検証状況

Node.js 18以降で、展開したフォルダーから次を実行します。追加パッケージのインストールは不要です。

```sh
npm test
```

牌枚数と物理牌の重複、和了判定、向聴、符・翻・点数、役とローカル役、対局進行、鳴き・リーチ・カン、保存復元などを検証するテストを収録しています。具体的な実施範囲と結果は[VERIFICATION.md](docs/VERIFICATION.md)を参照してください。

**自動テスト198件、Chromiumのブラウザ検証29項目を確認しました。** ブラウザ検証には実際のWebGL 2描画、8画面サイズ、3種類の埋め込みiframe、タッチ入力のエミュレーション、手牌選択、チー候補、数値設定、役一覧、保存ファイル読み込みを含みます。描画はSwiftShaderによるソフトウェア実行です。物理スマートフォン・各社GPU・音声出力・永続保存の実ブラウザ検証は未実施です。詳細と画像は[VERIFICATION.md](docs/VERIFICATION.md)に記録しました。

## 描画フレーム内のUI

設定は分類とページで切り替えます。ページ送りは「前へ」「次へ」、ホイール、上下スワイプ、PageUp／PageDownに対応。Tab／Shift+Tabで操作対象を移し、Enterで実行、Escapeで戻ります。数値は描画内の±ボタンと数字パネルから入力できます。横長では手牌を1行、縦長では2行に配置します。

最小の `index.html` はブラウザの起動に必要ですが、画面上の文字・牌・ボタン・設定画面はCanvasへ描画し、3D卓と同じWebGL画面に合成します。保存ファイルの選択だけはブラウザ標準のファイル選択画面を使用します。Canvas内の文字は通常のDOMテキストではないため、個別の読み上げに制限があります。設計は[CANVAS-UI.md](docs/CANVAS-UI.md)を参照してください。
