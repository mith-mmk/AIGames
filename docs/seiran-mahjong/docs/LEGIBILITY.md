# 牌面の視認性（2026-10-17 改訂）

この改訂では牌の大きさ・位置・ゲーム処理を変えず、色の薄さだけを修正しました。

- 萬子と字牌の主な文字を暗い藍色、索子を深緑、赤印刷を鮮やかな赤へ統一。
- 3D牌面は `MeshBasicMaterial` にして、`toneMapped: false` と `fog: false` を指定。卓の強い照明および ACES フィルム調の色変換によって顔料が白っぽくなるのを防ぎます。
- 側面と裏面の立体形状やライティングは変更しません。
- v1.0.1でHTML手牌の白いドロップシャドーを削除。v1.1.0は手牌自体をCanvasへ移し、この装飾を復活させていません。
- 操作できない時間帯も牌を半透明にしません（ボタンのクリック不可は維持）。
- 配布版のUIは端末のシステムフォントを使用し、フォントファイルを同梱しません。牌の字形は引き続き `glyphs.js` の独立した輪郭データを使用します。

描画品質を検証する際は、立体卓の河と手元のCanvas手牌で、色が大きく違わないことを確認してください。

## v1.1.0への引き継ぎ

UIの牌面は同じSVGをCanvasに描画します。手番外・操作不可でも不透明度を下げません。UI合成用マテリアルも照明・霧・トーンマッピングの影響を受けません。フレームのリサイズ時はGPUテクスチャを再作成し、旧サイズの画素が残って二重表示になる問題を修正しました。
