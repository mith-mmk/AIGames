## 保存試験の限界

この環境のブラウザは外部・ローカルHTTPのナビゲーションを制限されている。検証ではポリシーを変更せず、ローカルソースをabout:blankへ読み込んだ。そのため永続IndexedDBとlocalStorageは明示的なテストダブル、SHA-256は試験用のPython hashlib呼び出しを使用した。ゲームの本番コードにこれらの代用品を入れていない。ZIPの生成・読取・検証フローはブラウザで実行し、Nodeの試験ではWeb Cryptoも使用した。

したがって、ネイティブIndexedDBのディスク永続化、ブラウザを終了した後の実保存、実際のディスク容量不足、複数実タブ、標準ファイル選択・ダウンロードダイアログは未確認である。実機スマートフォン、タッチ端末の実機操作、音声出力、ハードウェアGPU、Safari/Firefox、公開先の認証・保存領域・動作も未検証。
