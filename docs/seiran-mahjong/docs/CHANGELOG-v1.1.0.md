# v1.1.0 — COMランダム・描画内UI

更新日: 2026-10-17

COMの設定に「ランダム」を追加し、すべての席の初期値にしました。新規対局の開始時に抽選し、その対局中と保存からの再開では固定します。12種類の打ち筋を個別に固定する従来の設定も残しています。

HTMLの画面構成と操作部品を廃止し、手牌・メニュー・設定・数値入力・保存・牌譜・図鑑・鳴き・和了結果・手牌分析を1つの描画フレーム内へ移しました。長い設定と説明は分類とページで切り替えます。外側のページをスクロールする必要はありません。

画面サイズ変更、横長・縦長、親画面より小さい埋め込みiframe、タッチとキーボードを検証しています。リサイズ後の古いUI残像を修正し、画素の比較テストを追加しました。小型の横長フレームでも手牌を1行に保持します。通知が打牌ボタンを覆わないよう位置も変更しました。

前版の牌面の濃い色、正確な34種類と赤牌の図柄、3Dの牌・自動卓・サイコロ、麻雀の進行・役・点数を維持しています。COM抽選、設定の初期値、描画UI以外の麻雀ルールの計算は変更していません。既存の保存キーと保存形式を継続使用します。

この更新はZIPに反映済みです。既存Sitesへの公開更新は未実施です。実行中のセッションにはSitesの再デプロイ操作がなく、公開URL上では旧版が残っています。
