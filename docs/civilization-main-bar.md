# メインバーと都市・部隊一覧

2026-09-10

- ヘッダーの下に生産・研究バーを常設。生産は都市を切り替えて現在と後続の最大5件、進捗、完了までのターンを表示する。都市管理を開かず追加・削除できる。研究は現行の1件ずつの方式で、対象・進捗・毎ターンの研究力・残りターンを表示し、その場で開始・変更できる。複数技術の予約機能は追加していない。
- 都市・部隊一覧は同じ枠のタブにまとめ、各ページ3件。前後ページとページ番号による移動に対応し、タブごとのページを保持する。積載中の部隊も一覧の件数に含める。都市選択は生産バーへ、都市内の部隊選択はその都市の生産表示へ連動する。
- 選択部隊の移動・待機等を詳細欄の先頭に置き、地形と同じタイルの部隊は展開式にした。詳細欄と一覧の高さを制限し、ターン終了・各種管理ボタンは常に表示する。移動計画ができると確定欄までスクロールする。
- 都市内のユニットは城壁の範囲に収め、地図に「駐留 n」を表示。選択見出し・部隊一覧にも都市名と駐留状態を表示する。都市を出ると駐留表示を解除する。駐留は所在の表示で、防御姿勢とは別。

## 確認結果

- 通常の保存データで都市の生産バーと駐留表示を確認。
- 検証専用の有効なスナップショット（24都市・120部隊・各都市5件の生産）を用い、部隊40ページ目の118〜120件、都市8ページ目の22〜24件まで操作できた。検証用ファイルは確認後に削除した。
- 生産の5番目を削除して偵察兵を追加し、5件上限で追加ボタンが無効になることを確認。研究を陶器から採鉱へ変更し、メインバーへ即反映された。
- 一覧から検証都市24を選ぶと、生産バーも検証都市24へ切り替わった。
- 都市11,4から部隊を12,3へ移動すると、駐留表示が消え、都市側の駐留数が5から4へ減った。移動確認ボタンも詳細枠内に収まった。
- 1366×768と1920×1080で目視。1366pxではサイドバーの表示高と内容高がともに536px、3件一覧の表示高と内容高がともに102pxで、件数による伸長なし。主要な部隊命令とターン終了は表示範囲内。細かな部隊情報は詳細欄をスクロールして参照する。
- `npm test` 成功（文明ゲーム13テストファイルを含む）。CSS互換性の警告7件、エラー0件。ブラウザエラー0件。

## 追加UIの調整と初期研究力の修正

- 生産と研究の背景・アクセント色を分け、生産中の項目を濃色で強調。後続項目は順番とユニット画像を表示する。進捗、キュー件数、停止理由もバーで確認できる。
- 研究バーは科学配分率と実際の研究力を別々に表示する。配分率から国家運営を開ける。研究力は都市基礎・交易・専門家・施設・技術の内訳を表示する。
- 旧実装で確認できた基礎研究は、人口比・生産比ではなく都市ごとの固定1RPだった。再構築時に抜けたこの基礎値を復旧した。都市がない場合は0RP、暴動・体制移行中の都市の研究は停止する。
- 交易の税・科学・娯楽を個別に切り捨てると、初期交易2・配分40/40/20ではすべて0になっていた。整数配分後の余りを小数部の大きい順に配り、同率では科学・税・娯楽の順にする。配分合計は交易量と一致し、配分0%には交易を割り当てない。都市基礎1RPは科学配分0%でも残る。
- seed 482731、64×40、6文明、速度1の初期都市で、都市基礎1＋交易1＝2RP/ターンを確認。ブラウザで陶器を研究開始し、次ラウンドに2/60RP、生産も2/25へ進んだ。
- 調整後の画面を1366×768と1920×1080で確認。ブラウザエラー0件。`npm test` 成功（文明ゲーム14テストファイルを含む、CSS互換性警告7件・エラー0件）。追加テストは整数配分の合計・誤差・0%配分、初期研究の実決算、基礎値と研究停止を確認する。
