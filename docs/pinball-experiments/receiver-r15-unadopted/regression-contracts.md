## Safe observation updates versus acceptance changes

- Correcting an obsolete collider index, classifying open surfaces by finite triangles, or using float-aware boundary distance improves observation. It does not by itself authorize changed gameplay assertions.
- New structural counts may be justified only after independent coverage/closure correspondence proves the intended actual shape. Generic behavior and all unmodified regions remain unchanged contracts.
- Any legitimate fixture migration must name the displaced part, old invalid state, relative approach being preserved, new initial all-solid clearance and required terminal event. Passing a relocated fixture must never erase the original regression.
- Termination should be defined as physical exit into the intended region, ordinary drain or completed same-ball route as appropriate. A timeout, tiny speed above a threshold, success score alone or reset is not a substitute.
- The full regression failure inventory must continue to distinguish stale observations, legitimately changed accepted contracts, invalid old starts, and unresolved genuine behavior. No wholesale expected-value update is authorized by this table.
